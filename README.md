# 🐺 宿舍狼人杀 · 局域网零后端

国庆宿舍版。一台手机当**法官主机**，其余手机连**同一个校园网**直连开局。
不用蓝牙配对、不用开热点、不用服务器、不用备案、不要钱。

- 平台：Android / iOS 通吃（一套 Flutter 代码）
- 身份牌只在你自己手机上，别人手机上看不到你的牌
- 标准法官流程：天黑闭眼 → 逐角色睁眼 → 天亮 → 警长竞选 → 发言 → 投票 → 放逐 → 胜负
- 外部依赖：**0 个 pub 包**，纯 Dart 标准库

## 玩法

1. 房主打开 App → **我是房主** → 选 6/9/12 人 → 点「开启房间」
2. 屏幕上会显示一个地址，比如 `10.16.22.31:7788` —— 念给室友 / 发群
3. 其他人打开 App → **我是玩家** → 填自己的名字 + 房主地址 → 进入房间
4. 坐满后房主点「发牌，开始第一夜」，每个人手机上只会亮出自己的身份
5. 天黑后房主依次点「叫 守卫/狼人/预言家/女巫 睁眼」，各人做完动作房主点「下一位」
6. 天亮 → 白天发言（房主口头控场）→ 点「开始投票」→ 所有人投票 → 结算放逐
7. 放逐后自动进入下一夜，直到狼全灭（好人胜）或狼 ≥ 好人数（狼人胜）

### 牌堆

| 人数 | 配置 |
|---|---|
| 6 | 狼×2 民×2 预言家×1 守卫×1 |
| 9 | 狼×3 民×3 预言家×1 女巫×1 猎人×1 |
| 12 | 狼×4 民×4 预言家×1 女巫×1 猎人×1 守卫×1 |

技能：狼人夜刀、预言家夜验、守卫夜守（不可自守，挡刀也挡毒）、
女巫一瓶解药一瓶毒药（各限一次）、猎人出局可开枪（女巫毒死的不能开枪）。

## 网络原理

```
房主手机                          室友手机们
┌──────────────┐                 ┌──────────────┐
│ dart:io      │  TCP :7788  ←→  │ LanGuest     │
│ ServerSocket │  一行一条 JSON  │ Socket       │
│ (法官主机)    │                 │ (玩家客户端)  │
└──────────────┘                 └──────────────┘
```

- 房主 App 内部起 `ServerSocket`，玩家是星形拓扑，消息都是 `{"t":"类型","d":{...}}`
- 房主显示自己的局域网 IPv4（`NetworkInterface.list()` 读的），玩家手输
- **零后端**：没有公网服务器、没有数据库、没有备案
- 同一个校园网即可；实在连不上就让房主开个人热点当临时局域网

### 为什么不用蓝牙

iOS 第三方 App 用不了经典蓝牙，BLE 在 8 台以上手机互联时会频繁掉线、还要逐个手动配对，
调试量是这套方案的 3 倍。宿舍场景校园网覆盖最稳，直接省掉这部分。

## 代码结构

```
lib/
  main.dart              首页
  core/judge.dart        ★ 裁判内核：牌堆/发牌/夜间结算/胜负（纯 Dart，可独立测）
  core/protocol.dart     ★ 网络协议
  net/lan.dart           ★ dart:io TCP 服务端 / 客户端
  ui/host.dart           房主：建房、法官台、投票统计、枪决
  ui/player.dart         玩家：身份牌、夜间动作、投票界面
  ui/common.dart         共用控件（身份大卡 / 选人格子 / 夜晚遮罩）
scripts/logic_check.dart ★ 内核自检（单进程，不需要 flutter）
build_apk.bat            一键出 APK
```

## 已知限制

- 白天发言没有强制计时（房主口头控场），要计时器可在 `_dayCard` 加 `Timer`
- 警长竞选做成房主口头主持，没有单独竞选 UI
- 房主手输地址给室友；想扫码就加个 `qr_flutter` 包
- 断线不会自动重连
