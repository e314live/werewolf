# 🐺 狼邮杀 · 局域网零后端

一台手机当**法官主机**，其余手机连**同一个 WiFi / 校园网**直连开局。
不用蓝牙配对、不用开热点、不用服务器、不用备案、不要钱。

- 平台：Android / iOS 通吃（一套 Flutter 代码）
- 身份牌只在你自己手机上，别人手机上看不到你的牌
- **人数随便定（6~18 人）**，牌堆自动配
- **屠边 / 屠城**两种胜负条件可选
- 端口被占用会自动顺延，不用手动改
- 外部依赖：**0 个 pub 包**，纯 Dart 标准库

## 下载

APK 在仓库右侧 **Releases** 页下载（公开仓库，不用登录 GitHub）：
<https://github.com/e314live/werewolf/releases/latest>

三个包按手机芯片选，绝大多数手机装 **arm64-v8a**：

| 包 | 对应设备 |
|---|---|
| `app-arm64-v8a-release.apk` | 2016 年后的手机（骁龙 7xx/8xx、天玑全系、麒麟） |
| `app-armeabi-v7a-release.apk` | 2015 年前的老机型 |
| `app-x86_64-release.apk` | PC 安卓模拟器（BlueStacks / MuMu） |

装的时候系统会问"是否允许安装未知来源应用"，允许即可。

> **升级不用卸载重装。** CI 用的是仓库里固定的一套签名证书（存在 GitHub Secrets，
> 不进代码库），所以每个版本的 APK 签名都一致，装新版会**直接覆盖旧版**。
> 早期版本因为签名每次都变，会出现"应用未安装"，装一次新包之后就正常了。


## 玩法

1. 房主打开 App → **我是房主**
2. 设人数（默认 9，可 ±，也有一排快捷人数）、选**屠边/屠城**、需要的话改端口 → 点「开启房间」
3. 屏幕上会显示一个地址，比如 `10.16.22.31:7788` —— 念给室友 / 截图发群
4. 其他人打开 App → **我是玩家** → 填自己的名字 + 房主地址（支持 `10.16.22.31:7789` 带端口）→ 进入房间
5. 坐满后房主点「发牌，开始第一夜」，每个人手机上只会亮出自己的身份
6. 天黑后房主依次点「叫 守卫/狼人/预言家/女巫 睁眼」，各人做完动作房主点「下一位」
7. 天亮 → 白天发言（房主口头控场）→ 点「开始投票」→ 所有人（含房主）投票 → 结算放逐
8. 放逐后自动进入下一夜，直到分出胜负

### 人数与牌堆

人数 6~18 任意，狼数默认按 `人数 ÷ 3 四舍五入` 自动算，房主也能手动加减。
神职最多 4 种（预言家 → 女巫 → 猎人 → 守卫，按优先级出场），剩下全是平民。

| 7 | 狼2 神2 民3 |
| 8 | 狼3 神3 民2 |

### 屠边 vs 屠城

| 模式 | 规则 | 适合 |
|---|---|---|
| **屠边**（默认） | 狼杀光**所有神职**，或杀光**所有平民**，狼胜 | 主流玩法，节奏快 |
| **屠城** | 狼必须把好人**一个不剩**全杀光，狼胜 | 人少局 / 新手局，拖得久 |

两种模式下「狼全灭 = 好人胜」都一样。判定逻辑在 `Judge.checkWinner()`，
自检脚本里专门有一组用例验证「同一中局在两种模式下结论不同」。

### 技能

狼人夜刀、预言家夜验、守卫夜守（不可自守，挡刀也挡毒）、
女巫一瓶解药一瓶毒药（各限一次，解药只能用在今夜被刀的人身上）、
猎人出局可开枪（被女巫毒死的不能开枪）。

## 网络原理

```
房主手机                          室友手机们
┌──────────────┐                 ┌──────────────┐
│ dart:io      │  TCP :7788  ←→  │ LanGuest     │
│ ServerSocket │  一行一条 JSON  │ Socket       │
│ (法官主机)    │                 │ (玩家客户端)  │
└──────────────┘                 └──────────────┘
```

- 房主 App 内部起 `ServerSocket`，玩家是星型拓扑，消息都是 `{"t":"类型","d":{...}}`
- 端口默认 7788，**被占用会自动往后试 12 个**，房主界面显示的是实际生效的端口
- 房主显示自己的局域网 IPv4（`NetworkInterface.list()` 读的），玩家手输
- **零后端**：没有公网服务器、没有数据库、没有备案

### 为什么不用蓝牙

iOS 第三方 App 用不了经典蓝牙；BLE 在 8 台以上手机互联时会频繁掉线、还要逐个手动配对，
调试量是这套方案的 3 倍。宿舍/教室 WiFi 覆盖稳定，直接省掉这部分。

## 代码结构

```
lib/
  main.dart              首页
  core/judge.dart        ★ 裁判内核：配牌/发牌/夜间结算/屠边屠城判定（纯 Dart，可独立测）
  core/protocol.dart     ★ 协议 + 地址解析（支持 IP:端口）
  net/lan.dart           ★ dart:io TCP 服务端 / 客户端（端口自动顺延）
  ui/host.dart           房主：建房、法官台、投票统计、猎人开枪
  ui/player.dart         玩家：身份牌、夜间动作、投票界面
  ui/common.dart         共用控件（身份大卡 / 选人格子 / 夜晚遮罩）
scripts/logic_check.dart ★ 内核自检 39 项（单进程，不需要 flutter）
test/widget_test.dart    UI 冒烟测试
assets/icon.png          应用图标（红月狼）
build_apk.bat            一键出 APK（Windows）
```

## 怎么跑

### 内核自检（不需要 Flutter）

```bash
dart run scripts/logic_check.dart
```

覆盖配牌（6~18 全覆盖）、洗牌、夜间顺序、守卫挡刀挡毒、女巫限次、
屠边/屠城判定、地址解析、回合推进。当前 **39/39 全绿**。

### UI 冒烟测试

```bash
flutter test
```

### 出 APK

双击 `build_apk.bat`，或：

```bash
flutter pub get
flutter build apk --release --split-per-abi
```

产物在 `build/app/outputs/apk/release/`。

推代码到 `main` 会触发 GitHub Actions 自动出 APK 并挂到 Release（见 `.github/workflows/build-apk.yml`）。

## 已知限制

- 白天发言没有强制计时（房主口头控场），要计时器可在 `_dayCard` 加 `Timer`
- 警长竞选做成房主口头主持，没有单独竞选 UI
- 房主手输地址给室友；想扫码可以加 `qr_flutter` 包
- 断线不会自动重连（重进会重新分配座位）

## 欢迎改

这是个给宿舍国庆局写的小工具，MIT 随便用。
想改规则就去 `lib/core/judge.dart`，纯 Dart 无依赖，改完 `dart run scripts/logic_check.dart` 一跑就知道有没有把逻辑改坏。
